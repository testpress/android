# AI Agent Guidelines

## Directives
- **Code modifications**: Read and comply with [CODING_STANDARDS.md](CODING_STANDARDS.md).
- **Commit format**: `<type>: <imperative subject>` (`feat`, `fix`, `ref`, `ci`, `chore`, `docs`). Max 100 chars. Reference issue if applicable (`Fixes #123`).

## Build & Test Commands
- **Assemble**: `./gradlew assembleDebug`
- **Unit Tests**: `./gradlew testDebugUnitTest`
- **Lint**: `./gradlew lintDebug`
